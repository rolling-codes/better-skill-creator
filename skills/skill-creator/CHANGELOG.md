# skill-creator changelog

The **canonical** release history for Better Skill Creator is the repository-root
[`CHANGELOG.md`](../../CHANGELOG.md). That file follows
[Keep a Changelog](https://keepachangelog.com/en/1.0.0/) and is what version
lockstep tests and GitHub releases use.

This packaged copy exists so a distributed `.skill` archive still carries a
pointer to project history. Do not maintain a second full changelog here — it
drifted through v3.5.x and caused release confusion.

**Current version:** see `skill.yaml` `version` (must match
`.claude-plugin/plugin.json` and `bsc.VERSION`).

**Full history:** https://github.com/rolling-codes/better-skill-creator/blob/main/CHANGELOG.md
